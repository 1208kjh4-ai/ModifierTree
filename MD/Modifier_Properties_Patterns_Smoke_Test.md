# 0.12.0 ON/OFF·하위 트리 복제·속성·Mirror·Array 확인

## 업데이트

Rhino 작업을 저장하고 완전히 종료한 뒤 실행합니다.

```powershell
cd D:\Project_Modifier
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\install-plugin.ps1
```

재시작 후 `MTreeStatus`에서 `0.12.0.0`을 확인하고 `MTree`로 패널을 엽니다. 기존 등록이 있으면 `.rhp`를 별도로 다시 드래그하지 않습니다. 0.9.0~0.11.0에서 저장한 트리도 열 수 있으며 기존 Modifier는 ON으로 복원합니다.

## ON/OFF

1. 겹치는 Box A/B를 등록하고 Boolean Difference 안에 A, B 순서로 넣습니다. A에서 B를 뺀 결과를 확인합니다.
2. Modifier 한 행을 선택해 하단 **Enabled** 체크를 해제합니다. 즉시 잘리지 않은 A가 보여야 합니다. 트리의 A/B와 이름·순서는 그대로이고 Modifier 행은 흐리게, State는 `OFF`로 표시합니다.
3. **State 셀을 더블클릭**합니다. 다시 ON이 되고 A-B 결과로 돌아와야 합니다. 이때 Name 셀은 기존처럼 이름 편집, InputWire 셀은 원본 선 표시를 전환해야 합니다.
4. OFF로 둔 채 B를 이동합니다. 출력은 A를 유지해야 하며, ON으로 켜면 이동한 B로 다시 계산해야 합니다.
5. OFF 상태에서 자식 순서를 B, A로 바꾸면 출력도 첫 자식 B로 바뀌어야 합니다. Undo 한 번으로 순서와 출력이 돌아와야 합니다.
6. B의 InputWire를 ON으로 설정한 뒤 Modifier를 OFF/ON 합니다. 설정은 유지되어야 합니다. OFF는 B를 이 연산에서 제외할 뿐 삭제하거나 트리 밖으로 꺼내지 않습니다.
7. 해당 Difference를 다른 Modifier 안에 넣고 OFF/ON 합니다. 상위 계산에도 첫 자식 또는 계산 결과가 전달되어야 합니다.

첫 자식이 비어 있으면 OFF 결과도 Empty이고, 첫 자식이 오류이면 그 오류를 무시하지 않습니다. 뒤쪽 자식의 오류는 OFF 출력에 영향을 주지 않습니다. **Show result**는 전체 미리보기 표시 설정으로 Enabled와 별개입니다.

## 속성 편집과 좁은 패널

1. Modifier 한 행을 선택하면 하단에 종류별 속성이 보여야 합니다. 원본 행이나 여러 행을 선택하면 속성 영역은 숨겨져야 합니다.
2. Name을 `Main`으로 입력하고 **Apply**를 누릅니다. `(BD) Main`처럼 종류 접두사를 붙여 표시해야 합니다. Name 셀 더블클릭 편집도 확인합니다.
3. Mirror 또는 Array에서 이름과 여러 숫자를 함께 바꾸고 Apply를 누릅니다. Undo 한 번으로 이름과 모든 설정이 함께 돌아오고 Redo로 함께 적용되어야 합니다.
4. 숫자를 입력하되 Apply 전 상태에서 뷰포트를 다시 그리거나 Enabled를 토글합니다. 미적용 숫자·이름이 지워지지 않아야 합니다. 다른 행으로 이동한 뒤 돌아오면 저장된 설정을 불러옵니다.
5. `NaN`, 잘못된 숫자, 0인 Mirror 법선, 소수 Array 개수, 총 256개를 넘는 Array 개수를 입력하고 Apply를 누릅니다. 아래에 오류를 표시하고 기존 결과·트리·Undo 기록은 바꾸지 않아야 합니다.
6. 패널을 약 180px 폭까지 줄이고 높이도 줄여 봅니다. Add Object 아래에 Add Modifier가 유지되고, 열과 버튼이 폭에 맞게 줄어야 합니다. 속성·작업 버튼 영역만 세로로 스크롤하며 트리는 별도로 보이고 조작할 수 있어야 합니다.
7. 기존 Shift/Ctrl 다중 선택 후 드래그가 유지되고, 다중 선택 시 Duplicate subtree/Bake/Merge 등 단일 Modifier 작업은 비활성화되는지 확인합니다.

숫자는 소수점 `.`을 사용합니다. 속성 Apply 전의 입력값은 `.3dm`에 저장하지 않습니다. Enabled는 Apply 없이 즉시 반영합니다.

## 하위 트리 복제

다음과 같은 중첩 구조를 준비합니다.

```text
Boolean Union
  (BD) Main
    A
    B
  (BD) Sub
    C
    D
```

1. `(BD) Main` 한 행을 선택하고 **Duplicate subtree**를 누릅니다. 같은 Union 안에서 원본 Main 바로 아래에 복제 Main이 들어가야 합니다. 루트 Modifier에서도 바로 다음 루트에 복제하는지 확인합니다.
2. 이름과 A/B 순서, 하위 Modifier 종류·Enabled·Mirror/Array 설정·InputWire가 그대로여야 합니다. 복제본 이름을 `Alternative`로 변경해 구분합니다.
3. 복제본의 B만 선택해 Move/Gumball로 이동합니다. 복제본의 결과만 바뀌고 원본 Main과 원본 B는 움직이지 않아야 합니다. Rhino 원본 객체는 서로 다른 GUID를 가져야 합니다.
4. 복제본에는 원본의 이름·레이어 등 기본 속성이 유지되지만 기존 Rhino 그룹에 속하지 않아야 합니다. 그룹 선택 때문에 원본과 복제본이 함께 움직이지 않는지 확인합니다. 복제본 자체의 잠금·숨김은 해제하며, 원본 레이어가 잠기거나 숨겨져 있으면 현재 레이어에 복제합니다.
5. 복제 작업 직후 Undo 한 번으로 복제 트리와 새 Rhino 원본들이 모두 사라지고, Redo 한 번으로 함께 복원되는지 확인합니다. 속성을 편집했다면 해당 편집을 먼저 Undo한 뒤 복제 Undo를 확인합니다.
6. 참조·누락·잘못된 형상 또는 제어점 편집 중인 원본이 포함된 경우 오류를 알리고 트리나 Rhino 문서에 일부 복제만 남기지 않아야 합니다.

복제는 실제 원본 객체를 늘리는 작업입니다. 원래 트리와 복제 트리는 이름이 같더라도 독립적입니다. 여러 행을 선택한 상태에서의 일괄 복제는 이번 범위에 포함하지 않습니다.

## Mirror

1. 월드 X 양수 쪽에 닫힌 Box 하나를 만들고 **Add Modifier → Mirror**에 넣습니다. 기본 YZ 평면 기준으로 X 음수 쪽에 대칭 결과가 생기고, **Keep original**이 켜져 있어 원래 쪽도 보여야 합니다.
2. Keep original을 끄고 Apply하면 대칭 쪽만 남아야 합니다. 다시 켜서 비교합니다.
3. YZ/XZ/XY 프리셋을 각각 선택하고 Apply합니다. 법선 방향이 각각 X/Y/Z로 바뀌어야 합니다. 프리셋은 현재 Plane origin 값을 유지합니다.
4. Plane origin을 `(5, 0, 0)`으로 바꾸고 YZ 평면을 선택해 Apply합니다. 대칭면은 월드 `X=5`가 되어야 합니다.
5. Plane normal에 `(1, 1, 0)`을 입력하고 Apply합니다. Custom plane으로 바뀌며 해당 법선의 임의 평면을 사용해야 합니다. 법선 `(0, 0, 0)`은 거부해야 합니다.
6. 원본 Box를 Move/Gumball로 이동합니다. **평면은 월드 좌표에 고정**되고 대칭 결과는 그 평면을 기준으로 다시 계산되어야 합니다. 전체 Modifier를 선택해 하위 원본을 이동해도 평면 자체는 따라오지 않습니다. 이동 취소·확정·Undo 이후 결과도 비교합니다.
7. Mirror 안에 원본을 더 넣거나 중첩 Boolean을 넣습니다. 모든 자식의 결과 조각에 대칭을 적용해야 합니다. 내부 원본을 수정하면 상위 결과도 갱신되어야 합니다.
8. Mirror를 OFF로 두면 Keep original 여부와 관계없이 첫 자식 결과만 표시해야 합니다.

대칭 결과는 추가 Rhino 객체나 트리 행이 아닌 미리보기입니다. 대칭 복사본을 개별 원본처럼 편집하려면 Bake/Merge로 고정합니다.

## 직선·격자 Array

1. 각 변이 5인 Box 하나를 **Add Modifier → Array**에 넣습니다. 기본 Count `(2, 1, 1)`과 Spacing `(10, 10, 10)`은 원본과 X 방향으로 10 떨어진 복사본을 표시해야 합니다.
2. Count `(4, 1, 1)`로 바꾸면 원본 포함 4개 위치가 X 방향 직선으로 나열되어야 합니다.
3. Count `(3, 2, 1)`, Spacing `(20, 15, 0)`으로 Apply하면 원본 포함 6개 위치의 격자가 나와야 합니다. Count Z를 2, Spacing Z를 10으로 바꾸면 12개 위치가 되어야 합니다.
4. Spacing X를 음수로 바꾸면 X 음수 방향으로 배치해야 합니다. 사용하지 않는 축의 Count는 1입니다. 간격은 문서 단위이며 월드 X/Y/Z 축을 사용합니다.
5. Count에 0, 음수, 소수 또는 곱이 256을 넘는 값을 넣으면 거부해야 합니다. Name을 함께 수정했더라도 잘못된 Apply에서는 이름도 바뀌지 않아야 합니다.
6. 원본의 위치·형상을 수정하면 전체 반복 결과가 갱신되어야 합니다. 이동 중 결과, Esc 취소, 확정, Undo/Redo를 확인합니다.
7. Array에 두 개의 원본이나 하위 Modifier를 넣으면 전체 입력 묶음을 각 격자 위치에 반복해야 합니다. 배치 위치는 최대 256개이며 복잡한 중첩에서는 결과 조각 총 4,096개 제한도 적용합니다.
8. Array를 OFF로 두면 첫 자식의 원래 결과만 보여야 합니다. ON으로 복귀하면 저장된 개수와 간격을 다시 사용해야 합니다.

복사본은 미리보기입니다. 개수만큼 실제 Rhino 원본이나 트리 행이 생성되면 안 됩니다. 간격이 작아 겹치더라도 Array 자체는 조각을 Boolean 합집합으로 만들지 않습니다.

## 중첩 Boolean과 Bake/Merge

1. Mirror 또는 Array를 Difference의 첫 자식으로 넣고, 여러 복사본을 가로지르는 Cutter를 두 번째 자식으로 넣습니다. 모든 해당 위치에 잘림이 적용되어야 합니다.
2. Mirror/Array를 Difference의 Cutter로도 사용합니다. 여러 복사본이 모두 차집합에 반영되어야 합니다.
3. 서로 겹치는 배열 조각과 다른 원본을 Union/Intersection의 두 입력으로 사용합니다. 상위 Boolean은 복사본 조각 전체를 한 입력의 합집합으로 계산해야 합니다.
4. 이름을 지정한 Mirror/Array에서 Bake합니다. 원래 트리를 유지하면서 이름이 같은 고정 Brep 한 개가 루트 맨 위에 추가되어야 합니다. 고정 결과는 원본을 움직여도 변하지 않아야 합니다.
5. 중첩된 Mirror/Array에서 Merge합니다. 해당 노드와 하위 트리만 고정 Brep 한 개로 교체하고 부모·형제 위치를 유지해야 합니다. 기존 원본은 Rhino에 숨겨 보관합니다.
6. Bake와 Merge 각각 Undo 한 번으로 완전히 되돌리고 Redo로 복원합니다. 그 앞뒤에 Enabled·속성 Apply·복제·일반 Move를 섞어 연속 Undo/Redo를 확인합니다.

Bake/Merge는 떨어지거나 겹치는 조각을 한 Brep에 담으며 자동으로 겹침을 합치지 않습니다. 다른 입력과 상위 Union으로 계산한 뒤 Bake하면 그 Union 결과를 고정합니다. Boolean Modifier는 ON 상태에서 두 개 이상의 입력을 사용합니다.

## 저장과 다음 실행

1. Boolean/Mirror/Array가 중첩되고 일부 Modifier가 OFF인 트리를 만듭니다. 이름·비기본 설정·InputWire와 복제본도 포함합니다.
2. 필요한 속성은 Apply하고 `.3dm`을 저장한 뒤 Rhino를 종료합니다.
3. 재실행하여 파일을 엽니다. 플러그인이 로드되고 종류·이름·부모·순서·Enabled·Mirror 평면·Keep original·Array 개수와 간격·InputWire가 유지되어야 합니다.
4. 복제본의 원본을 다시 편집해 원래 트리와 독립적인지 확인합니다. OFF를 ON으로 바꾸면 저장된 설정과 현재 입력으로 계산해야 합니다.
5. 0.11.0에서 저장한 파일도 별도로 열어 기존 구조와 결과가 유지되고 Modifier가 ON인지 확인합니다.

저장에는 미리보기 형상이나 Undo 기록을 넣지 않습니다. 파일을 열 때 실제 원본과 저장된 트리 설정으로 결과를 다시 계산합니다.

## 자동 검사와 수동 확인 구분

2026-09-11 Release 0.12.0 최종 빌드는 오류·경고 0개이며, Core 141개와 Rhino 411개, **총 552개 검사**가 통과했습니다. 수동 확인이 필요한 연속 Undo/Redo 관련 3개 항목은 자동 통과 수에 포함하지 않습니다. [빌드 기록](../artifacts/validation/0.12.0/release-build-2026-09-11.txt), [Rhino 검사 기록](../artifacts/validation/0.12.0/rhino-checks-2026-09-11.txt).

자동 검사는 저장 스키마·검증·복제 원자성·한 번의 Undo, Mirror/Array 형상·중첩·이동 중 계산, 속성의 미적용 입력 유지·유효성 검사와 실제 Eto/WPF 좁은 패널 배치를 포함합니다. 실제 키·마우스 조작과 Rhino 플러그인의 파일 열기·자동 로드 전체는 이 문서의 수동 절차로 확인합니다.

이전 0.11.0은 2026-09-10 자동 검사 396개를 통과했고, 2026-09-11 사용자가 업데이트 후 정상 동작을 확인했습니다. 이전 기능의 세부 재검사는 [0.11.0 확인 순서](Multi_Select_Boolean_Smoke_Test.md)를 사용합니다.
