# Modifier Tree 0.4.0 이동·표시 화면 검증

작업을 저장하고 Rhino를 재시작한 뒤 `artifacts/bin/0.4.0/Release/net8.0-windows/ModifierTree.rhp`를 로드합니다.
`MTreeStatus`의 버전이 `0.4.0.0`인지 확인합니다. 같은 폴더의 동반 DLL은 유지합니다.

## 표시

1. 겹치는 Box A와 B를 등록하고 빈 Difference의 자식으로 넣습니다.
2. 기본 상태에서 결과만 보이고 A·B 입력 선은 보이지 않는지 확인합니다.
3. 패널에서 B를 선택하고 **Show this input in viewport**를 켭니다. 주황색 B 선이 보여야 합니다.
4. 다른 행을 선택하거나 뷰포트를 클릭해도 설정이 유지되어야 합니다. 다시 B를 선택해 체크를 끄면 숨겨져야 합니다.
5. B를 다른 Modifier로 옮겨도 개별 표시 설정이 유지되어야 합니다. 최상위로 꺼낸 객체는 일반 원본으로 표시됩니다.
6. Perspective를 Shaded, 다른 뷰를 Wireframe으로 둡니다. 결과가 각 뷰의 면·선 설정에 따라 다르게 표시되어야 합니다.
7. 첫 원본의 객체/레이어 색을 바꾸고 결과에 반영되는지 확인합니다. Ghosted의 투명도와 Rendered의 기본 재질도 확인합니다.
8. **Show result** OFF는 모든 원본을 일반 표시합니다. ON은 입력 표시 설정대로 복귀합니다.

표시 차이를 보고할 때는 표시 모드 이름과 화면을 함께 기록합니다. Raytraced와 고급 렌더 효과의 완전한 일치는 이번 버전의 완료 기준이 아닙니다.
계산 실패 시 원본을 다시 보여주는 기존 복구 동작은 유지합니다. Select in Rhino로 명시적으로 선택한 입력은 Rhino 편집 명령 중 조작을 위해 일반 표시합니다.

## 전체 이동

1. Difference 행을 선택하고 **Move**를 누릅니다.
2. 기준점과 도착점을 지정합니다. 이동 중 노란 선으로 위치가 표시되어야 합니다.
3. 완료 후 A와 B가 같은 거리만큼 움직이고 Boolean 형태는 유지되어야 합니다.
4. Undo 한 번으로 A·B·결과가 함께 돌아와야 합니다. Redo로 다시 이동되어야 합니다.
5. Move의 기준점 전, 기준점 지정 후 각각 Esc를 눌러 원본이 변하지 않는지 확인합니다.

## 중간 Modifier와 개별 원본

다음 구조를 구성합니다.

```text
Boolean Difference
  Boolean Difference
    A
    B
  C
```

- 중간 Difference 선택 → Move: A·B만 움직이고 C는 유지됩니다. 최상위는 이동된 (A−B)에서 C를 다시 뺍니다.
- B 행 선택 → Move: 숨겨진 B도 패널에서 움직일 수 있으며 A·C는 유지됩니다.
- 각각 Undo/Redo를 확인합니다.
- B를 Rhino에서 Lock하거나 삭제한 상태에서 상위 Move: 일부 원본만 이동하지 않고 이유를 명령창에 표시해야 합니다.

## 검증 범위

자동 검사는 30개 Core/GUID 검사와 58개 Rhino 엔진 검사를 통과했습니다. 실제 문서 원본 이동과 한 번의 Undo 복원도 포함합니다.
화면 없는 검사 호스트에서는 Undo 후 새 Undo 기록 시작과 직접 Redo 호출에 제약이 있어 이동 시나리오마다 새 문서를 사용했습니다. Redo와 UI 이벤트에 따른 자동 재계산은 위 절차로 확인해야 합니다.

이번 버전의 Move는 패널 선택과 MTreeMove 명령을 사용합니다. 결과 직접 선택, Modifier Rotate/Scale/Gumball, 트리 저장과 트리 구성 변경 자체의 Undo는 아직 지원하지 않습니다.
