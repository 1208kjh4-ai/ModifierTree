# 0.7.1 — 뷰포트에서 전체 선택과 내부 편집, 검볼 활성화

Rhino를 종료하고 프로젝트 루트에서 아래 명령으로 업데이트합니다. Rhino를 다시 시작해 `MTreeStatus`의 버전이 `0.7.1.0`인지 확인합니다.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\install-plugin.ps1
```

트리는 아직 세션 전용입니다. 겹치는 상자 A/B를 등록하고 빈 Boolean Difference에 A, B 순으로 넣습니다. InputWire는 둘 다 OFF, Show result는 ON으로 둡니다. 처음에는 Gumball을 꺼 두고 선택 후 자동으로 켜지는지 확인합니다.

## 기본 흐름

1. Shaded 또는 Rendered에서 결과의 면을 한 번 클릭합니다. 패널은 Modifier 행을 선택하고, 결과의 모서리가 노란색으로 나타나며 기본 검볼이 표시되어야 합니다. Wireframe에서는 모서리를 클릭합니다. 검볼이 이미 켜진 상태에서도 선택을 해제했다가 다시 선택해 검볼이 나타나는지 확인합니다.
2. Gumball 또는 Rhino Move로 이동합니다. A/B가 같은 거리만큼 함께 이동하고 상대 위치와 Boolean 결과 모양이 유지되어야 합니다. Undo 한 번으로 모두 복귀하는지 확인합니다.
3. Gumball 핸들을 피해서 결과를 더블클릭합니다. Modifier State가 `Editing`으로 바뀌고 A/B 모서리가 하늘색으로 보여야 합니다. InputWire는 OFF를 유지해야 합니다.
4. B의 모서리를 클릭합니다. B만 노란색이 되고 패널도 B 행을 선택해야 합니다. 검볼은 B의 선택에 맞춰 나타나야 합니다. 이동하면 A는 고정되고 실시간 최종 결과가 갱신되어야 합니다. B는 이동 중에도 면 없이 모서리만 보여야 합니다.
5. 이동 도중 Esc를 누릅니다. 이동만 취소하고 내부 편집은 유지되어야 합니다. 명령이 끝난 뒤 Esc를 누르면 전체 선택으로 돌아와야 합니다. 입력 선은 기존 InputWire 설정으로 돌아갑니다.
6. 다시 내부로 들어가 완전히 빈 공간을 더블클릭합니다. 한 단계 밖으로 돌아와야 합니다. 일반 빈 공간 한 번 클릭은 선택만 해제해야 합니다.

## 중첩·실패·기존 UI

- `(A-B)-C` 구조에서 최상위 클릭은 A/B/C 전체, 첫 번째 내부의 자식 Modifier 클릭은 A/B, 한 단계 더 들어가 B 클릭은 B만 이동해야 합니다. Esc는 한 단계씩 복귀해야 합니다.
- 두 Modifier가 겹쳐 보이면 Shaded의 앞쪽 결과를 선택하는지 확인합니다. 일반 Rhino 객체가 앞을 가리면 그 객체를 선택해야 합니다.
- 결과의 구멍이나 잘려 나간 빈 부분을 클릭해 숨겨진 원본 면이 단독 선택되지 않는지 확인합니다.
- Gumball 핸들 조작·더블클릭, 뷰포트 회전/확대, 실행 중 명령의 점 선택이 정상인지 확인합니다.
- 잠긴 원본, 잠긴 레이어, Rhino에서 숨긴 원본 또는 누락 원본이 있으면 Modifier 전체 선택을 거절하고 이전 선택을 유지해야 합니다.
- 패널에서 Modifier와 원본 각각의 Select in Rhino 및 Move를 확인합니다. 이름 더블클릭, InputWire 더블클릭, 트리 드래그가 유지되어야 합니다.
- 패널의 Select in Rhino로 선택해도 검볼이 나타나야 합니다. 빠른 더블클릭으로 내부에 진입한 직후에는 전체 검볼이 남지 않아야 합니다. 빈 공간에서 선택을 해제하면 검볼도 사라져야 합니다.
- 내부 편집 중 노드를 옮기거나 제거하면 최상위 선택 범위로 돌아가야 합니다. 문서 전환과 닫기 후 다른 문서에서 이벤트가 간섭하지 않아야 합니다.
- Show result OFF에서는 일반 Rhino 선택으로 돌아가야 합니다. 다시 ON으로 켜면 결과 선택을 사용할 수 있어야 합니다.

## 자동 검사의 범위

Core 39개와 Rhino 엔진 103개 검사를 통과했습니다. 추가 검사는 편집 범위의 진입·복귀, 전체/부분/단독 원본 선택, 잠금·숨김·누락 시 부분 선택 방지, 선택에 따른 객체·그룹 생성 없음, 실제 Brep의 면 교차와 모서리 선택을 포함합니다. 0.7.1은 전체·개별 선택이 Rhino의 명령 종료에도 유지되는 persistent 상태인지 검사합니다. 검볼의 실제 표시·마우스 이벤트 순서는 화면 검증 대상입니다.

0.7.0은 코드로 선택한 뒤 Redraw만 호출했습니다. 0.7.1은 마우스 처리 이후 Idle에서 현재 문서와 선택을 다시 확인하고 `_Gumball _On`을 한 번 실행합니다. 선택/내부 편집 전환 중 낡은 요청은 버리며, 기존 검볼의 위치나 정렬을 초기화하는 Reset은 사용하지 않습니다. [McNeel의 기본 검볼 표시 안내](https://discourse.mcneel.com/t/show-gumball-on-selected-objects/99161/4)를 참고했습니다.

화면 없는 호스트의 메시 선택 API는 네이티브 뷰가 없을 때 종료되어 사용하지 않습니다. 최종 코드는 Brep와 클릭 방향의 실제 교차를 사용하며, 이 경로는 같은 호스트에서 검증했습니다. 실제 마우스 콜백과 Gumball/그리기 이벤트의 결합은 위 화면 확인이 필요합니다. 호스트의 직접 Redo API는 기존 기준 검사에서도 실패하므로 실제 Rhino에서 확인합니다.

이번 구현은 일반 왼쪽 클릭과 더블클릭 기준입니다. Shift/Ctrl·창 선택·명령 내부 객체 선택은 Rhino 기본 선택입니다. 결과가 없는 Modifier는 패널에서 선택합니다. 미리보기 Bake/내보내기, 트리 저장, 복제 시 트리 복사와 계산 속도 개선은 포함하지 않습니다.
